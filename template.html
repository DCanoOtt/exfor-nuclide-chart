EXFOR nuclide chart

How many experimental data sets EXFOR holds for each target nuclide, for any neutron-induced reaction. Choose the reaction, the kind of data and the Z and A ranges; drag a box on the chart to zoom, click a nuclide for the details.

How to use this chart

What you see

Each square is one target nuclide: neutron number N across, proton number Z up, element symbol at the left end of each row. The colour is the number of EXFOR items you chose to count for neutron-induced reactions on that target. Squares without data show the background colour. Projectiles other than neutrons are not included, and natural elements (A = 0) cannot be placed on a chart of nuclides.

Reading and navigating

  • Hover a square: nuclide, value, and the split of its data sets into SIG, RP and other.
  • Click a square: all reactions of that nuclide in the panel below the chart; click a reaction there to switch the chart to it.
  • Drag a box on the chart to zoom in; all text and numbers grow with the squares. Whole chart resets the ranges.
  • The table "Largest values in view" lists the 15 highest squares; click a row to select it.
  • Copy table (CSV) copies the visible values (Z, element, A, N, value) to the clipboard.

Reaction and count

Reaction
EXFOR process of the neutron-induced reaction: capture (n,γ), fission, elastic, inelastic, (n,p), (n,α), total, resonance parameters (n,0), and so on, or all of them together. The number after each name is its number of data sets.
Count
Data sets: reaction records with a data table. EXFOR entries: distinct experiments (one entry can hold many data sets). Data points: rows of the tables. RP resonances: rows of resonance-parameter tables, counted for RP data sets only.

Data filters

Measurement method
All data, time-of-flight only (METHOD field contains TOF), or everything except time-of-flight.
Quantity
The first group of the list holds SIG, RP, RYL (reaction yield) and Other (everything else); below it come all quantity codes in alphabetical order. Tick one or several entries in the list; a data set is kept if it matches any ticked entry (for example SIG + RP + RYL), and nothing ticked means all quantities. There is a search box and an "All quantities" button. SIG cross sections. RP resonance parameters: resonance energies, spins J, orbital momenta L and widths (WID). RP are not stored as SIG. Other everything that is neither SIG nor RP (angular and energy distributions, yields, spectra, ratios, resonance integrals, strength functions...). Below these, any single EXFOR quantity code with its number of data sets.
Points per data set
Keep only data sets whose table has at least (and optionally at most) this number of rows. For RP tables this is the number of resonances. Use 20 or 100 to keep substantial measurements.
Publication year
First and last year of the main reference of each EXFOR entry (journal, conference or report year). Leave both empty for the complete period, or fill in one limit only. Entries whose reference has no usable year are left out while a period is set, unless you tick the box.
Neutron energy range
Lowest and highest incident-neutron energy of each data set, converted from the units of the table and compared in the unit you choose (eV, keV, MeV; MeV is the internal unit). You can fill in only one limit. "Overlaps" keeps data sets that touch the range, "lies inside" those entirely within it, "covers" those spanning all of it. Data sets without any incident-energy information (Maxwellian or spectrum averages, fission yields, spectra...) are left out while a range is set, unless you tick the box.

Range

Limits on Z, N and mass number A. They combine: a square is shown only if it satisfies all three. Zooming with the mouse fills in Z and N.

Colours

Palette
Spectrum, Turbo, Viridis, Plasma, cool-to-warm, Blues, Greens and Reds.
Maximum in black
The top colour is black (white on a black background), so the most heavily measured nuclides stand out. Untick it to keep the palette's own end colour.
Background
Colour of squares with no data: white, light grey or black.
Scale
Log gives low values their own colours (best for counts spanning orders of magnitude); square root and linear stress the large values. "Top of the scale" fixes the value that gets the last colour, to compare charts.

Saving the picture

"Save image" redraws the chart at the resolution you choose (96 to 1200 dpi) and offers it as PNG or JPEG. The picture has the on-screen layout, so zoom and choose the filters, palette and window size first. At 300 dpi a chart of 1000 px on screen becomes about 3125 px, with text and lines sharp. PNG files carry the dpi value in their metadata. The browser asks you to confirm the file name before saving; where direct saving is not offered, the image is shown below the button to save with a long-press or right-click.

Display

Radioactive nuclides carry a dashed diagonal pattern (stable ones are plain); the hover tooltip also says "stable" or "radioactive". A nuclide counts as stable when no decay has been observed; very long-lived ones such as 209Bi, 232Th, 235U and 238U are radioactive here. Numbers in the squares appear when they fit (or always/never). You can switch on element names, grid lines, the magic numbers 2, 8, 20, 28, 50, 82, 126 and lines of constant mass number.

Glossary

Data set
One reaction record with a data table in an EXFOR entry. Sums, ratios and other complex reactions are not included.
Entry
One EXFOR experiment (an accession number such as 23453) with a bibliography and one or more data sets.
SIG
Cross-section data set (EXFOR quantity code SIG).
RP
Resonance-parameter data set (codes EN in the (n,0) reaction, J, L, WID, WID/STR, WID/RED and related).
Reference list
After you click a nuclide, the References panel lists the publications (EXFOR entries) behind its data sets that pass the current filters and the chosen reaction: first author, year, journal or report, title, the EXFOR entry and subentry numbers (linked to the IAEA-NDS EXFOR web service) and how many data sets and points each contributes. Sort it or copy it as text.
TOF
Time-of-flight measurement, for example at n_TOF (CERN), GELINA or ORELA.
N, Z, A
Neutron, proton and mass number of the target.

About, data licence and citation

The numbers are computed from the EXFOR master files of the IAEA Nuclear Data Section (licence CC BY 4.0) when the page is built, and are embedded in this file: the page works offline. Please cite EXFOR (N. Otuka et al., Nucl. Data Sheets 120 (2014) 272) and state the data date shown in the footer. The footer links to the source code and the instructions for rebuilding the page with a newer EXFOR release.

Good to know

  • Counts follow the EXFOR master files of , including superseded data sets.
  • "All reactions together" can count the same entry or points under several reaction types.
  • The point count of a data set is not clipped to the energy range.
  • If a count looks wrong, hover the square: the tooltip shows the split of its data sets, and the clicked-nuclide table shows all reactions with and without the current filters.

Counts come from the EXFOR master files of . A data set is one reaction record with a data table; its size is the number of points in that table. Sums, ratios and other complex reactions are left out, natural targets (A = 0) cannot be placed on the chart, and superseded data sets are included. Time-of-flight data are those whose METHOD field contains TOF. Resonance parameters (RP) are not stored as SIG: they are tables of resonance energies (reaction (n,0)), spins, orbital momenta and widths (WID, WID/STR, WID/RED), and each row of such a table is one resonance, so a resonance may appear in an energy table and again in a width table. Entries and points counted for "all reactions" can repeat across reaction types. The energy filter uses the lowest and highest incident-neutron energy of each data set (from EN, EN-MIN/MAX, EN-RES or the resonance-energy column, in the units of the table); points are not clipped to the range.
